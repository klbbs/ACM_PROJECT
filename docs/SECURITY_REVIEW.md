## 新交题和同步接口

- 只向固定 HTTPS 官方域名发送，拒绝跨域重定向；Cookie 只放入该平台会话，不回显到错误、任务或公开记录。
- 发送前验证当前官方身份、表单 CSRF、题目和实际编译器；选项与提交时分别读取，不能只因 Cookie 已保存就认为能提交。
- 代码来自已经保存的不可变版本。固定 request_key 幂等；发送结果不明时停止自动重试，进程重启不重发代码。真正发送前再次检查站内登录与账号凭据版本。
- 判题独立核验账号、题号、提交号、时间。源码不存在也可同步判题；不能把当前草稿自动声明为历史提交源码。
- 本题同步只写当前账号、当前题目的提交，不改变全历史水位、个人主页快照或其他题目。查询范围和部分成功对调用方明确返回。
- 官方源码只从已核验归属的原始提交页读取，遇到重定向或结构变化停止；不默默替换正在编辑的草稿。不支持自动源码读取的平台保留结果并解释限制。
- 采用既有站内会话、CSRF、Origin、每用户数据库及高成本限流；AI 失败不影响判题持久化。自动错因提示仍须用户开启。
