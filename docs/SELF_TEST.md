# 代码自测

网站后端只转发至管理员的专用 Judge0 服务，不在网站进程内运行或编译用户程序。可执行语言从该服务的 `/languages` 实时读取并按固定白名单匹配 C++17、C++20、Python 3、Java 17；缺少的语言版本不能运行。

## 配置

在服务器 `.env` 设置后重建网站容器：

```dotenv
ACM_SELFTEST_URL=https://YOUR-DEDICATED-JUDGE0
ACM_SELFTEST_KEY=YOUR-SERVER-AUTH-TOKEN
```

Key 仅以 `X-Auth-Token` 发给固定服务，不返回浏览器。服务须由管理员维护，独立于网站及私人数据库，启用 Judge0 自身沙箱与队列限制、保持安全更新，禁止从公网匿名调用。网址不可由网站成员指定。内网受控连接可以使用 HTTP，跨公网使用 HTTPS；禁止重定向。

未配置时，工作台明确显示禁用和本地运行建议；不会退回网站宿主机执行。安装网站本身不会自动安装或启动 Judge0。

## 使用和限制

在工作台输入代码，展开“代码自测 · 自定义输入”，选择原题样例或填写自己的输入。可选填预期输出，再同意将本次代码和输入发送给管理员的隔离服务后运行。页面显示标准输出、错误、编译信息、用时和内存；预期比较忽略行尾空白及末尾空行，不执行平台的特殊判题器。

网站固定设置单次执行、CPU 2 秒、墙钟 5 秒、128 MiB 内存、64 KiB 文件输出上限、32 进程/线程，禁用网络和单独线程额外资源额度。请求总等待最多 30 秒，最多每用户 1 个、每网站进程 2 个自测。服务可能对不同语言有额外限制，以实际结果为准。Judge0 服务必须实际执行这些约束，不能把一个普通执行接口当作沙箱。

网站不持久化自测结果；Judge0 自身可能保存代码、输入和运行结果，运维需设置访问权限及保留策略。更改代码、语言或输入后，页面清除旧结果以防误读。自测只检查给定输入，不能证明平台 AC，不会生成提交记录或签到。

协议参考：[Judge0 CE 官方 API 文档](https://ce.judge0.com/)。本版本后端使用模拟 HTTP 验证协议/资源限制，浏览器使用合成运行结果检查交互；实际执行需在配置好的 Judge0 服务单独验收。
