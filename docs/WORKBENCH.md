# 刷题工作台

工作台支持 Codeforces、AtCoder、洛谷和牛客的题面与样例获取，以及统一 AI 小提示。各平台访问权限和反爬限制不同；失败时显示原因并保留已有缓存。图片附原链接，公式与 Markdown 渲染展示；无法自动获取时可导入官方题面节点 HTML，导入内容不能作为官方共享译文来源。

## 使用流程

1. 在「连接与设置」添加平台账号，填写正确 handle / UID。信息采集与登录检测分开；需要 Cookie 时先保存，再点「检测登录状态」，确认实际账号一致。详见 [平台绑定教程](PLATFORM_BINDING.md)。
2. 从推荐列表选择题目、输入官方链接，或在「提交记录」点击「回到工作台」。历史记录可打开题面，但公开采集通常不含历史源码，不会自动恢复当时的代码；已有当前草稿会保留。查看历史源码请前往官方记录，权限允许时自行复制。
3. 编辑器支持 C++17/20、Python3、Java17，本地补全使用 Tab 接受、Enter 换行，可选 Vim。代码最多 64 KiB，自动保存并显示结果；冲突时先手工复制当前代码再决定如何恢复。详见 [编辑器说明](EDITOR.md)。
4. 自测控制台紧贴代码编辑器下方、位于同一卡片并默认展开，全屏编辑器也可直接使用。可填入原题样例或自定义输入与预期输出，由管理员配置的隔离服务执行；未配置服务时明确禁用。自测 PASS 只代表当前输入的执行/比较结果，不是官方 AC，不能签到。详见 [代码自测](SELF_TEST.md)。
5. CF、AtCoder 可点击「读取平台编译器」检查官方身份并选择实际编译器，随后「提交到平台」。本站保存本次代码后仅发送一次，取得官方提交号并自动读取判题；WA 等错误可按用户已开启的偏好请求 AI 提示。出现浏览器验证或登录失效时停止并提示，不能以已保存 Cookie 代替实际身份。洛谷、牛客当前仍在官方网页提交。
6. 如果在外部平台交题，点击「同步本题提交」即可获取当前题目记录，不要求手填提交号、粘贴代码或勾选代码校对。记录同步与当前草稿无关；有当次代码记录可查看、复盘，无代码时可尝试读取本人官方源码。读不到源码仍保留判题，只是不能凭空分析代码。查询范围和平台延迟会明确显示，旧记录不会因空结果被删除。

旧版客户端的手动关联接口仍保留兼容。该接口会核验官方账号、题号、提交号及有效的官方提交时间。本人确认当前代码对应该条提交后，可关联先提交、后粘贴或保存代码的记录，也可复盘自己的较早提交；本地保存时间不再作为判断源码是否对应的证据。源码对应关系属于本人声明，始终标记为未自动核验，不能用当前代码覆盖已经关联的另一份代码。签到、每日任务仍以官方提交日期计算，关联以前的 AC 不会完成今日签到。旧内部代码记录须在主关联表单中明确确认后才能关联更早的提交；仅刷新旧记录不会自动补充声明。缺少账号、提交号格式错误或未确认代码时，卡片会说明按钮不可用的原因。

## 收藏与个人备注

题面标题下方可收藏当前题目并编辑个人备注，手动点击保存。左侧「收藏与备注」支持搜索并回到工作台；取消收藏保留已有备注。收藏与备注存于当前用户自己的数据库，刷新后仍保留，不加入共享题面、共享翻译或自动 AI 上下文。备注未保存或保存中时会阻止站内换题、切页并提示处理；版本冲突时保留本地文字，不自动覆盖另一页面的改动。

## 调整题面与编辑器布局

打开题目后，在题面上方选择「工作台布局」：

- **自动适配**：可用区域足够宽时左右排列，较窄时题面在上、编辑器在下；按实际内容区域判断，收起侧栏或选题栏会增加可用空间。
- **左右分栏**：拖动中间带握柄的分隔线调整占比。选中分隔线后，左右方向键每次调整 2%，Shift 加方向键调整 10%，Home/End 到达允许边界；双击恢复各占一半。
- **上下排列**：题面完整展开，编辑器和自测在其下方，适合笔记本、手机或需要较宽代码区域的场景。

为保持可读性，两栏有最小宽度；即使选择左右分栏，空间不足仍会自动上下排列，变宽后恢复偏好比例。「重置布局」恢复自动适配与 50/50 比例。布局保存在当前用户数据库，刷新和更换设备后沿用，用户之间隔离；保存失败会提示并可重试。切换布局不重建编辑器，保留当前代码、撤销记录和自测输入；刷新后代码由已保存草稿恢复，撤销记录不跨刷新保存。

## AI 与数据边界

每次提示只提供一个短切入点和一个问题，每题最多 8 次，不请求完整解法。选择模型后直接点击“给我一个小提示”或“分析本次错因”，无需额外勾选；提示发送题面与提示历史，错因分析另发送所选代码和判题结果，按钮旁有说明。普通历史采集没有源码，不能分析不存在的旧代码。记录列表不会自动关联当前草稿。只有实际读取的当次官方源码可标记已核验；本地保存或本人旧版声明的代码仍明确保留其来源。模型推测不等于已证实的错误，也不能编造隐藏测试。

源码、Cookie 和 API Key 不会因共享翻译而公开。训练概览和推荐使用当前用户统计与练习摘要；共享翻译需本人主动上传并经管理员审核。私人译文仅在内存暂存，批准的共享译文才长期保存。左侧匹配指数表示推荐匹配程度，并非通过概率。

题面翻译会按文本量分批，AI 批次同时遵守用户配置的输出上限；因此一次长题面可能产生多次调用。任一批网络、配额、输出格式或公式校验失败都会停止，保留原题与旧译文，失败原因显示在翻译面板内。不会自动重试或保存半份译文。若提示输出被截断，可提高 AI 设置中的输出 token 上限或换用合适模型；Google/Bing 需要管理员配置对应官方翻译服务，不能用普通 AI Key 替代。

个人草稿、提示、关联判题与分析数据沿用每用户独立数据库和会话/CSRF/来源校验。旧版本已有的内部代码记录为兼容历史数据保留，但不再提供“先保存快照再交题”的用户流程；不要把它们当作官方源码。个人数据库和凭据不能上传仓库或放入静态目录。

部署见 [DEPLOYMENT.md](DEPLOYMENT.md) 与 [MULTIUSER.md](MULTIUSER.md)。Codeforces 判题接口参考 [官方 API methods](https://codeforces.com/apiHelp/methods)。

## 自动错误提示

自动错误提示默认关闭。在工作台选择 AI 模型，明确同意发送题面、当次关联代码与官方判题信息后，才可开启。关联或刷新官方 WA/CE/TLE/RE 等错误结果时，AI 给出一个自查方向和一个引导问题，不提供完整解法或修复代码；AC、判题中和未知状态不触发。

相同代码及官方结果只自动请求一次，网络失败可手动重试。关闭后取消在途请求并拒绝旧结果写回；已经发送给提供方的请求可能已计费。关闭偏好不占 AI 调用预算，仍受会话与 CSRF 保护。自动分析使用开启时确认的模型；手动提示独立。

## 发送结果不明时

提交后网络中断可能发生在平台接收之后，本站不会立即重发。先查询本次任务或官方记录；没有提交号且仍不确定时，只有本人确认官方未受理，才能解除阻塞重新提交。重启服务不重发代码。判题刷新只读取结果，不发送代码。自动代交目前实现 CF/AtCoder 协议与隔离验收，真实可用性还取决于服务器网络及有效登录；本轮 CF 真实交题待更新会话，AtCoder 真实 POST 尚未验收。
