# 0.21.4 平台读取与 Gym 翻译开发记录

## 读取入口

本次只改本地代码，不更新或重启线上服务。回退仅使用已知的官方公开页面、同一资源的正常表示或项目原先支持的公开索引；不解决验证码、不伪造登录身份、不重复发送解题代码。

| 数据 | 正常读取与备用入口 | 限制 |
| --- | --- | --- |
| CF 用户资料 | 用户 API → 官方个人主页 | 核验 handle；只保留页面实际提供的字段 |
| CF 提交与判题 | 用户/比赛 API → 官方用户提交列表 | 核验账号、提交号、比赛、题号及明确时区；分页有界，不能冒充全量同步 |
| CF Gym 提交 | 比赛 API → 既有官方 Gym 状态列表 | 保留既有日期、身份与比赛范围校验；远程代交 Gym 仍不支持 |
| CF 源码 | 官方提交详情 → 本人官方列表的源码弹层 | 独立核对同一提交、账号和官方 CSRF；弹层 POST 只读取源码，绝不包含或提交代码 |
| CF 题面 | 既有 problemset/contest 官方题面表示 | 所有入口均失败时保留旧缓存；不把挑战页缓存为题面 |
| CF 评级、完整题库 | 原官方 API 与既有缓存 | 未找到可信的完整替代时明确失败，不用零条覆盖旧数据 |
| AtCoder 资料/提交 | 官方资料页与既有 AtCoder Problems 公开索引 | 主页受限不阻断索引；公开索引不能证明已登录，缺失资料明确标记 |
| AtCoder 判题/源码 | 官方详情 → 同比赛、同用户的官方提交列表 | 列表只能证明判题；不能当作源码，源码详情受限后不重复请求 |
| AtCoder 题面 | 官方英文/日文 task 表示 | 仍核验题面结构；不改变题号或比赛 |
| 洛谷题面/资料 | 官方 HTML → 同资源 Accept: application/json 内容协商 | 仍需正常官方数据结构；不是另一种登录方式 |
| 牛客题面及其他读取 | 既有公开读取与本用户已保存官方会话 | 无可信备用入口时明确失败；扫码与手动 Cookie 绑定仍是独立方式 |

共享读取层识别 HTTP 200/503 的真实挑战标记、普通 403/418 和 429；题面或源码里提到验证的普通文本不构成挑战。429 优先于挑战标记，遵守原有有界退避，耗尽后停止入口切换；可选评级请求的限流也不能被忽略后继续读取。CF API 正文的明确限流提示同样处理。

同一判题会话记住已经受限的读取入口，避免每次轮询重复探测；记录包含账号范围，不持久化或跨用户共享。真实交题 POST、登录 POST 不参与读取入口回退或自动重放。前端遇到验证、登录失败、访问限制或限流会暂停自动刷新。

## 数据可信度与已知限制

- 用户列表回退最多读取 3 页（判题/本题同步）或 5 页（账号采集）；范围与比赛 API 的最多 600 条不同，超出覆盖范围标记不完整，不推进采集检查点。
- 列表缺少明确时区、账号不匹配、团队记录、重复分页或缺少提交证据时保守拒绝；不猜测时间后增加排行榜数量。
- 源码弹层只在本人可核验列表包含目标提交时使用，旧提交不在当前列表中仍可能无法读取。判题记录保留，不拿其他提交或编辑器草稿替代。
- 此前授权诊断中曾确认 CF 用户列表可读、登录仍有效，而详情和官方源码弹层均返回访问限制。因此本版增加备用入口并改善诊断，不能保证从受限服务器读取源码。没有把 Cookie 有效等同所有接口均可访问。
- 日志只记录固定原因，不保存上游原文、源码、Cookie、密码或 API Key。

## Gym 翻译

原实现要求模型原样返回随机公式占位符，任意删除、转义、调序或重复都会导致整篇拒绝保存。当前没有拿到用户失败时的原始模型响应，不能断言具体是哪一种损坏；修复从结构上消除了 AI 翻译对占位符复述的依赖。

- 首次翻译前在服务器拆出自然语言，公式、代码和链接占位符留在服务器，按原位置与原空白拼回；不根据受损模型输出猜公式，也不追加恢复重试。
- 原始样例、图片、HTML 属性和数学渲染容器继续保护；新增旧 KaTeX 字形及非 `pre` 样例容器的保护，普通输入输出说明仍可翻译。
- 仍核验条目编号、顺序、完整性、长度和跨批模型来源；拒绝在纯文字结果中添加新公式、代码、链接或伪造占位符。失败不保存半篇译文。
- 文字片段可能增多，仍按现有字符和 48 条上限分批，最多 64 批且发请求前检查；75 个公式段落的合成用例产生 76 条文字串、2 次初始调用。不是所有题面只调用一次，也不承诺翻译免费。
- 共享译文审核、去重、临时私人译文和权限流程沿用原实现；普通 Google/Bing API 的请求流程不变。
- 子代理的翻译与 AI 策略定向检查 58 项通过。Hermes 首轮提出的额外收费重试、旧数学字形和样例保护问题已在最终实现中移除或补齐；Hermes 对最终代码的第二轮只读复核未发现阻塞问题，未声称代替测试或真实模型验证。

上述检查使用合成题面和模型响应，没有调用收费 AI，不代表真实模型语义质量或线上防护已验收；本轮没有部署。
