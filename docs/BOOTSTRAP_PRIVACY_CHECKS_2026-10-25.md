# 自由初始化与仓库隐私开发检查

本轮针对反馈中的首次部署身份与源码隐私进行本地开发检查，没有连接、修改或部署线上服务，没有改版本号或重写 Git 历史。

## 行为

- 空用户库由部署者自行指定首位管理员用户名、可选昵称及密码；用户名沿用既有格式约束，昵称支持中文，空昵称回退用户名。
- 初始化仍要求部署令牌且只能执行一次；密码强度、哈希、CSRF、会话与管理员审批机制保持有效。
- 已有数据库启动及离线维护不再执行按固定用户名改名、删除、降权或撤销会话的历史迁移；保留用户 ID、密码、昵称、资料和私人目录。
- 初始化昵称和首位身份在同一事务内写入，默认不公开主页或榜单。
- README、旧公告、历史说明中的个人管理员别名与个人目录改为通用描述；容器临时测试使用合成身份，不作为部署默认值。

## 已执行

- 前端定向：`members.test.tsx`、`administrator-requests.test.tsx`，6 项通过。

身份测试使用临时本地数据库；验证了自选用户名和昵称、错误令牌及弱密码拒绝、二次初始化拒绝、旧用户与额外管理员不变、旧会话保留、审批机制继续有效。不代表真实服务器部署或平台登录验收。

## 隐私扫描范围

检查当时的 405 个已跟踪文件后，非合成测试内容中未再发现个人管理员别名或个人 home 路径候选。私有配置文件名的提交历史查询未发现实际账号配置、`.env`、数据目录或授权文件被提交的记录；扫描 1623 个历史唯一文件对象的私钥、常见 token 与相关密码形态，未发现需输出的候选。扫描只报告路径和类别，不输出匹配值。

这属于定向模式扫描，不等同完整的外部秘密审计。当前匿名化不会擦除旧提交中的历史管理员别名；若以后发现秘密曾泄露，应先轮换或撤销，再由仓库管理者决定是否清理历史。
