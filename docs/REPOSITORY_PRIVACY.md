# 源码、初始化与私有数据

新部署不附带任何默认管理员账号或密码。部署者在首次初始化页自行设置用户名、可选显示昵称和密码，使用本机私有配置中的部署初始化令牌确认身份。初始化令牌不是用户密码，不应发布到仓库、聊天记录或日志。

升级不会按历史用户名执行重命名、删除、降权、转移资料或撤销会话；已有管理员和成员继续使用原身份。忘记密码时，先备份并停止服务，使用离线密码恢复工具，密码通过隐藏输入提供，不放在命令参数中。

提交源码和制作发布包时应仅包含通用配置示例：

- 站点地址使用 `acm.example.com` 等示例域名；个人目录使用 `$HOME` 或明确的项目路径占位。
- 不包含真实平台账号密码、Cookie、API Key、用户数据库、浏览器授权或个人服务器地址。
- `.env`、实际账号配置、`data/`、浏览器资料和发布包受现有忽略及打包白名单保护；文件被忽略不等于已从旧提交中删除。
- 测试中的账号和密码为合成样例，不是可用于部署的默认凭据。容器冒烟账号只存在于临时测试数据中。
- 运行日志只保存固定事件和脱敏字段，不记录秘密、题面、提交源码或报告正文。

如果秘密曾被推送，即使当前文件已经删除，仍应先撤销会话或轮换密码与密钥，并由仓库管理者评估历史清理。本次开发不会擅自重写 Git 历史，也不会连接或修改线上服务。
