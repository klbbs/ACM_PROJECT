# 0.18.3 开发交付

本次未部署，未操作服务器。源码、测试、构建和无凭据部署包由 GitHub 版本管理。

- Cookie保存支持单行前缀整理，修复合法连续点号误拒；编辑展示服务器已保存、项数及具体错误，留空保留、输入替换、显式清除，保存后自动检测支持的平台。
- CF、AtCoder 的服务器密码及远程浏览器登录受 Cloudflare 阻止，按用户决定删除这两条路线。现在统一由本人浏览器官方登录后使用油猴 Cookie 助手，回本站粘贴、保存并检测。卡片提供官方登录、助手下载和教程入口，并提示按助手结果确认 Cookie 完整性。后端不再接受这两平台的浏览器启动请求，旧密码接口删除。见[平台登录方式](PASSWORD_LOGIN.md)。

- 本次补读当前站点分区 Cookie，真实 CF、AtCoder 油猴导出集合与 Firefox 一致，且后台身份匹配；洛谷导出一致，但后台仍 HTTP418。见[实机记录](acceptance/2026-10-20-v0.16.1/COOKIE_EXPORT.md)。

- 牛客卡片提供官方微信扫码登录，服务器获取二维码并自动轮询，真实当前 UID 确认后才绑定；用户及站内登录会话隔离、过期/取消/注销清理，旧请求不能覆盖新账号。本人已在微信关联牛客账号后完成新二维码登录、当前身份及绑定连续验收；修复官方成功响应 data=null。见 [真实扫码验收](acceptance/2026-10-21-platform-login/NOWCODER_QR_LOGIN.md)。
- 洛谷保留官方浏览器窗口，本人已完成新官方登录至检测绑定的连续验收。窗口收到官方页面响应后即可显示，点击及文字逐次实时发到官方页面；输入完成后仍需官方登录和最后的检测绑定。见 [登录记录](acceptance/2026-10-21-platform-login/VALIDATION.md)。

- 工作台题面与编辑器可拖动调整比例，也可改为上下排列；自动布局以实际可用宽度适配，用户偏好保存在独立数据库，切换保留编辑器状态。

- 自测控制台已放到编辑器下方同一卡片，默认展开，适配全屏与窄屏，点击运行才发送代码，保留过期结果检查。
- 两个「同步平台题库」按钮共用任务闭环，在候选区域给出进度、逐平台失败原因及当前筛选排除说明；读取失败与启动失败分开提示。详细流程见 [同步题库说明](RECOMMENDATIONS.md)。

- 「主要目录」作为登录首页；按开始训练、记录与社交、连接与管理分类。功能搜索支持 Cookie、翻译、自测等关键词；首次使用可直达平台与插件教程。侧栏与目录共用同一权限过滤注册表，移动端和收起侧栏可用。

- 平台 Cookie 助手改用油猴脚本，提供源码复制安装与下载导入；不再主推未签名 Firefox 临时扩展。脚本1.0.2只在固定官方页面主动读取，无 HttpOnly 时可明确选择复制可读部分并提示可能不完整；API空结果提供页面可读备选，完整凭据仍可用F12获取。
- CF检测增加常见会话字段辅助排查，最终仍以CF返回的当前身份匹配为准；油猴教程提供官方Firefox Beta入口和授权步骤。真实Firefox+官方Beta已完成CF及AtCoder当前会话导出与身份检测；不扩充其他平台代交。洛谷保留官方窗口、公开资料同步及官方网页交题，手动Cookie卡片不提供无效的访问限制处理提示。
- 平台检测区分验证码、服务器访问限制、限流和网络失败，提供官方处理入口与跳过旧缓存的主动重检；浏览器验证不保证服务器出口通过。
- 绑定教程、安装说明与账号设置合并到同一页；保留工作台教程快捷入口。
- 更新公告登录后提示未读，已读状态按用户保存在服务器数据库，支持跨设备与历史回看。维护流程见 [插件与公告](BROWSER_EXTENSION.md)。

- 推荐：所有最近验证登录的平台混合抽样；推荐/每日任务/换题共享真实日期下限、已做及对战排除。
