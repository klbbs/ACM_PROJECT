# 0.14.0 开发交付

本次未部署，未操作服务器。源码、测试、构建和无凭据部署包由 GitHub 版本管理。

- 新增网站内下载的四平台 Cookie 插件（Chromium 与 Firefox ZIP），按当前域名授权、当前容器读取，点击复制后手动粘贴并检测；Firefox 为未签名临时测试包。
- 绑定教程、安装说明与账号设置合并到同一页；保留工作台教程快捷入口。
- 更新公告登录后提示未读，已读状态按用户保存在服务器数据库，支持跨设备与历史回看。维护流程见 [插件与公告](BROWSER_EXTENSION.md)。

- 推荐：所有最近验证登录的平台混合抽样；推荐/每日任务/换题共享真实日期下限、已做及对战排除。
- 目录：CF 完整带难度官方题库；AtCoder 最近六场、洛谷和牛客列表为有限发现范围，非完整题库。无法确认日期的题严格排除有日期要求的推荐。
- 自动教练：用户明确选择开启、模型和代码发送许可；默认关闭。官方错误才触发，去重、取消与重新校验避免多次付费和旧结果写回。
- 社交：默认私有主页与榜单；认领验证身份后参与榜单，用户可自行公开范围。源码、凭据和私人分析不公开。
- 对战：双方好友、精确 CF 难度、时长和接受流程；官方 API 完整核验历史，官方 AC 时间判胜；对战题不计入每日任务或 K 签。
- 当前仍需官方页面交题；不声称已支持 Cookie 自动代交。对战核验为用户主动操作，没有新增后台定时任务。

使用步骤与边界见 [推荐](RECOMMENDATIONS.md)、[社交与对战](SOCIAL.md)、[工作台](WORKBENCH.md)。
