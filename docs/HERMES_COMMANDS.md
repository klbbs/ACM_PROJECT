# QQ /roll 调用入口适配

服务端 `topic` 支持多类别表达式；外部桥接程序也须放开仅接受“分数 + 单题型”的旧命令限制。仓库提供不依赖网页框架的 `acmhermes.commands`，以及可选迁移工具。它们不调用模型、发消息、启动或重启进程。

- `/roll 1800 dp&博弈论`：显式分数、同时满足。
- `/roll dp&博弈论`：省略分数、同时满足。
- `/roll dp|博弈论`：省略分数、任一类别。
- `&` 和中英文逗号表示交集，优先于 `|`；最多 8 项，不支持括号。

省略分数时先使用**当前聊天 scope** 上一轮有效分数；没有有效历史才在已认证会话中读取 `GET /api/training`：先取有效 `goal_rating`，否则取有效 `minimum`～`maximum` 中点。有效分数要求整数且在 800～3500 内。没有有效配置就明确提示用户设置或显式填分，不暗定 1800 等默认值。不会读取另一个聊天的历史，也不会自行访问管理员配置。

仍在生成的任务继续按原请求键恢复；作答中的共享题仍复用。以上分数解析只用于真正开始新一轮，不改变已冻结请求正文、排重快照、投递回执或付费请求重试规则。仅在分数解析后按原流程检查就绪、保留轮次和提交。恢复入口 `/roll text` 的原有语义保持。

## 可选本地桥接迁移

迁移工具只支持经确认的 `practice_core.py` / `practice_backend.py` 结构。路径由操作者提供，仓库不保存私人桥接源码、数据库、账号或聊天内容。

```sh
python3 scripts/patch_hermes_bridge.py --directory /path/to/your/bridge
python3 scripts/patch_hermes_bridge.py --directory /path/to/your/bridge --apply
```

第一条仅输出拟变更文件。第二条先创建权限 0700 的备份目录（原文件 0600），再更新两个调用文件并复制轻量 `acm_roll_commands.py`。未知结构、符号链接、部分迁移和规划后并发变更都会中止；重复执行无变化。写入失败时尽力恢复原文件。工具不会输出源码、凭据或消息，不会执行桥接文件，也不会修改正在运行的 Python 进程；由管理员自行安排进程加载代码。

回滚时，在进程停止或管理员安排的维护窗口，依据备份清单恢复原有两个文件；若 `acm_roll_commands.py` 原本不存在，则移除新复制的该文件。不要将私人备份提交 Git。

测试使用临时合成桥接文件和模拟认证接口，不代表真实 QQ 发消息、真实 OJ 抽题或线上付费 AI 验收。
