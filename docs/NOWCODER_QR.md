# 牛客官方微信扫码登录

适用版本：0.16.0。入口在「连接与设置 → 平台信息、登录检测与交题 → 牛客」。服务器无需图形桌面或浏览器扩展。

## 用户操作

1. 选择「自动识别我的牛客 UID」，或限定为已经绑定的某个 UID。限定后若手机登录的是其他账号，本次绑定失败，原有账号不会被替换。
2. 确认由本人扫码、授权将登录会话保存到自己当前的 ACM Lab 账户，再点击「获取微信登录二维码」。
3. 用本人微信扫描二维码，按照手机上的牛客官方流程确认。需要关注、登录或补全资料时，由本人在官方流程处理；本站不收集微信/牛客密码、短信验证码。
4. 页面每三秒查询结果。只有服务器从牛客官网确认当前 UID 后，才显示「身份验证通过」并刷新绑定列表。扫码成功码本身不等于已绑定。
5. 二维码最多约两分钟有效，可取消或刷新。失败时可使用原有牛客官网登录 → 油猴/F12 → 粘贴 Cookie → 检测的方式。

请只扫描自己在可信 ACM Lab 页面主动生成的二维码。二维码包含一次性登录授权信息，不要发给别人或加入工单截图。

## 会话与保存

临时 Session、票据及二维码只在服务进程内存中；前端只收到二维码图片和本站随机流程 ID，不返回上游票据 URL、Cookie 或原始响应。图片不写日志、数据库、本地存储或共享缓存。取消、到期、替换、注销、撤销会话和服务关闭都会使临时流程失效。

多人模式同时绑定站内用户及当前登录会话；其他用户或同账号的另一浏览器无法查询/完成此流程。上游请求只访问固定牛客官方端点及固定微信二维码图片路径，禁止任意图片代理与未知回调跳转。

真实身份验证通过后，Cookie 按现有规则保存在用户独立目录的私有账号配置文件中（0600权限），不向前端返回。不保存平台密码。绑定使用账号版本检查及锁内合并：扫码期间账号配置变化、采集进行中、UID不匹配均不会覆盖旧凭据。

## 排查

- 申请失败：检查服务器能否访问 ac.nowcoder.com 与 mp.weixin.qq.com；本站展示固定失败提示，保留 Cookie 后备入口。
- 二维码过期：重新获取，手机只确认最新一次二维码。
- 已扫码但身份未确认：可能需要官方补全账号或完成额外登录回调；当前不会自动访问未知回调网址，也不会冒充绑定成功。
- 返回频繁请求：生成至少间隔10秒，查询至少间隔3秒；每个应用进程最多32个未完成流程、4个同时进行的上游请求。
- 重启或多进程：临时流程不跨重启共享，同一次扫码的 start/poll/cancel 必须路由到同一个应用进程。多个 worker 需会话粘滞，或后续改用专门共享的安全临时会话服务。
