# 牛客官方微信扫码登录

适用范围：当前开发分支，尚未标注新版本。入口在「连接与设置 → 平台信息、登录检测与交题 → 牛客」。服务器无需图形桌面或浏览器扩展。

## 用户操作

1. 先选择「微信扫码（推荐）」；扫码与「导入浏览器 Cookie」是两种替代方式，选一种即可。扫码成功已保存会话，无需再从浏览器导入 Cookie。选择「自动识别我的牛客 UID」，或限定为已经绑定的某个 UID。限定后若手机登录的是其他账号，本次绑定失败，原有账号不会被替换。
2. 先在牛客官方站点将本人微信关联到牛客账号，再点击「获取微信登录二维码」；点击即申请将本次扫码会话保存到自己当前的 ACM Lab 账户。
3. 用本人微信扫描二维码，按照手机上的牛客官方流程确认。需要关注、登录或补全资料时，由本人在官方流程处理；本站不收集微信/牛客密码、短信验证码。
4. 页面每三秒查询结果。只有服务器从牛客官网确认当前 UID 后，才显示「身份验证通过」并刷新绑定列表。扫码成功码本身不等于已绑定。
5. 二维码最多约两分钟有效，可取消或刷新。失败时可使用原有牛客官网登录 → 油猴/F12 → 粘贴 Cookie → 检测的方式。

请只扫描自己在可信 ACM Lab 页面主动生成的二维码。二维码包含一次性登录授权信息，不要发给别人或加入工单截图。

## 会话与保存

临时 Session、票据及二维码只在服务进程内存中；前端只收到二维码图片和本站随机流程 ID，不返回上游票据 URL、Cookie 或原始响应。图片不写日志、数据库、本地存储或共享缓存。取消、到期、替换、注销、撤销会话和服务关闭都会使临时流程失效。

多人模式同时绑定站内用户及当前登录会话；其他用户或同账号的另一浏览器无法查询/完成此流程。上游请求只访问固定牛客官方端点及固定微信二维码图片路径，禁止任意图片代理与未知回调跳转。

真实身份验证通过后，Cookie 按现有规则保存在用户独立目录的私有账号配置文件中（0600权限），不向前端返回。不保存平台密码。绑定使用账号版本检查及锁内合并：扫码期间账号配置变化、采集进行中、UID不匹配均不会覆盖旧凭据。

## 排查

- 申请失败：检查服务器能否访问 ac.nowcoder.com 与 mp.weixin.qq.com；本站展示固定失败提示，保留 Cookie 后备入口。
- 二维码过期：重新获取，手机只确认最新一次二维码。
- 扫码后仍在等待：牛客 `code=1` 的扫码/确认状态文案可能变化，ACM Lab 会继续轮询到确认或二维码过期；只有官方状态成功且固定首页能验证当前 UID 后才绑定。若到期仍未完成，请确认微信已关联牛客账号、在手机上完成确认后重新获取二维码。当前不会自动访问未知回调网址，也不会冒充绑定成功。
- 返回频繁请求：生成至少间隔10秒，查询至少间隔3秒；每个应用进程最多32个未完成流程、4个同时进行的上游请求。
- 重启或多进程：临时流程不跨重启共享，同一次扫码的 start/poll/cancel 必须路由到同一个应用进程。多个 worker 需会话粘滞，或后续改用专门共享的安全临时会话服务。

协议和合成测试见[协议核对](acceptance/2026-10-20-nowcoder-qr/PROTOCOL.md)、[独立安全验收](acceptance/2026-10-20-nowcoder-qr/SECURITY_REVIEW.md)。本人已在2026-10-21完成全新手机扫码至身份验证及绑定，见[真实结果](acceptance/2026-10-21-platform-login/NOWCODER_QR_LOGIN.md)，不能用合成上游测试代替。

## 2026-10-23 验收记录

本轮核对仍以 2026-10-21 本人扫码记录为历史实测依据，没有重新登录、读取私人 Cookie 或进行新的真实手机扫码。

- 已有服务端实现正确处理 **HTTP 200、JSON `code=0, data=null`**：同一会话接收 Set-Cookie，再读取固定牛客首页验证当前 UID。HTTP 200 本身不是扫码成功，JSON `code=200` 也不是已确认的微信成功协议。
- 微信尚未绑定牛客、首页不能确认身份、目标 UID 不一致、账号配置已变化、取消/过期/退出或旧在途请求均不得覆盖既有绑定。扫码成功保存 `login_method=qr` 的服务端会话，不再要求手工导入另一份 Cookie。切换登录方式只切换 UI；仅完成并验证新的方式后才更新该账号凭据。
- 修复 UI 边界：缺失有效 UID 或流程 ID 不匹配的 `verified` 响应不能显示“已绑定”；409 配置冲突等后端安全提示保留展示；二维码在申请期间过期时清晰提示重新获取，不显示成未知协议错误。
- 本轮代码验收通过，但真实扫码链路未重新执行，因此不声称今日手机扫码通过。再次真人验证时，微信需已关联牛客账号，扫描当次最新二维码，并核对页面显示的 UID 与本人账号一致。
