# Hermes 可选接口与 AC 代码评估：开发记录

后续说明：用户于 10 月 29 日要求移除截图，Hermes 已改为直接返回 AI 阅读后的中文题目说明与解题报告，无需浏览器或额外整页翻译。下文为 10 月 28 日原始开发记录；当前接口见 [接入文档](HERMES_API.md)。

本次为本地开发，保持 0.21.6；未连接服务器、部署、更新公告、打标签或制作新发布包，尚未进行版本验收。

## 改动

- `acmhermes` 独立命名空间、`hermes` 可选依赖与 `ACM_ENABLE_HERMES` 默认关闭开关。关闭时不挂载接入端点；普通功能无需 Playwright/Markdown 渲染依赖。
- `POST /api/hermes/draw` 仅接收必填分数区间及可选题型，沿用本人认证、CSRF、成本限流、任务预算和默认 AI。真实候选初选、完整官方题面确认、完整解题报告、结构保护翻译、无网络截图渲染与下载串联。
- 幂等请求键及只读恢复接口防止响应丢失时重复付费；同一请求只选一道，不自动换题或重试模型。GET 不调用 AI。报告绑定题号、题面指纹及配置，拒绝候选外题目、资格失效和配置变化。
- 截图使用保持沙盒的 Chromium 与本地 KaTeX，外部请求全部阻断，图片以链接文字保留；分页完整导出，超限不截断冒充成功。个人翻译正文不写数据库，截图短期清理，报告仅在本人任务库保存。
- 提供轻量 Hermes SDK（不保存认证信息、不自动重试 POST、不跟随结果中的任意 URL）和接入文档。
- 工作台 AC 记录提供「AI 代码评估」，失败提交继续错因复盘。复用已核验源码绑定、结果指纹及私人存储；AC 专用提示词和结构涵盖思路、复杂度、代码风格、健壮性、优点、替代方法及不确定性，不使用编辑器草稿，不运行代码，不改变判题或签到。

## 定向开发自检

- 后端 154 项通过：Hermes 接口、工作台、提交源码、专项评估及直接受影响的 AI 提示词/schema。覆盖默认关闭、参数约束、幂等、无浏览器/无模型、错题号与不适用报告、配置/题面变化、截图过期、CSRF 和多用户隔离；AC 评估核对精确源码、保留草稿、源码变化拒绝保存及不改变签到。
- 前端提交相关 57 项通过，包含 AC 评估入口、独立结果展示、无需载入编辑器，以及现有失败提交与远程跟踪回归；TypeScript 与生产构建通过。
- SDK 与实际本地截图渲染另 3 项通过。真实启动 Chromium，使用合成中文、数学公式和长正文输出两页 PNG，核对页尺寸及完整分页；手工查看第一页确认中文和不等号公式可读。此检查不访问 OJ 或模型。
- 自动化选题、报告、翻译及平台响应均为合成数据，不代表真实模型效果或平台验收。没有运行整个项目检查。
- 开发环境原虚拟环境缺少当前解释器的依赖，按项目约束补齐本地依赖与 Hermes 可选组件；前端新测试最初调用辅助函数参数错误、默认关闭预期 404/405，以及截图 Python API 参数问题均在定向自检中修正后通过。
