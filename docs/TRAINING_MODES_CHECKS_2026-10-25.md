# 训练分类与四阶段修订：开发检查

按反馈拆分为三个本地协作分支：完整算法目录与共享选题服务、每日随机/专项训练、专项界面与无复选框操作；主代理负责集成、提示词、安装数据、文档与检查。协作分支合并保留提交历史，只推送 main。版本保持 0.20.4，不部署、不打标签或创建新发布。

## 最终行为

- 使用洛谷公开标签字典的 262 个 Algorithm 节点、22 个根分类，保留父子路径、层级、来源版本及旧 ID 兼容；明确 CF 标签映射同时可供搜索和候选匹配。
- 用户选择新学、巩固、变式、加强；仅新学强制可信模板首题，其他阶段无模板也能生成，不改变用户所选阶段。
- 独立专项与每日训练均自由输入 1～50 题；每日选择随机或专项。随机材料使用近期统计、错误分布、知识点覆盖，不发送源码或账号凭据来推断能力。
- 每日专项复用同一选题服务，不额外创建独立计划。今日题数、专题、阶段与选题方式一起锁定，修改偏好不影响今日题单或 Roll 配额。
- 专项 Roll 先按相同平台的已知相邻题难度过滤候选，再调用 AI；失败保留题单并退回机会，不跨平台换算分数。
- 训练生成、评估、追问移除静态同意复选框；仅显式按钮 POST 发起。旧客户端可继续传 consent=true，新客户端不要求此字段；源码绑定、认证、CSRF、限流及预算仍保留。

真实平台题库可用性、用户的已做题排除与模型教学质量仍待指定验收。新学在没有合格未做模板时明确失败，不用普通题冒充；巩固、变式和加强不会因缺少模板而被拒绝。
