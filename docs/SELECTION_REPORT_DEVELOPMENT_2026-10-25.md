## 前序反馈修复

- 同步公开题库后独立采集当前用户已配置账号在北京时间今日的官方提交；两部分分别展示结果，提交采集失败不会丢失题库结果。单独同步提交入口保留，避免在题库任务尚在执行时再次提交重复采集。
- 已验证当前凭据的平台身份自动安全关联榜单，保留跨用户唯一约束、凭据变更失效与主动退出后不自动恢复的保护。榜单每行增加“查看当日题目”，展示官方链接、原平台难度/分数、标签和当日题目数量，切换日期/栏目使旧请求失效。
- 排行榜仍按官方提交时间归日，同题去重；不能把今天同步的历史 AC 当成今天做题，也不能将自测或 AI 判断计入。
- 洛谷兼容当前 name 名称字段；补充官方模板分页和专题定向列表、AtCoder Library Practice；专题匹配与模板优先发生在随机截断前。专项允许继续训练尚未 AC 的尝试题，从本人全部已验证平台共同筛选，不借用其他用户的凭据。
- 失败说明具体的平台、模板、可靠发布日期、CF 难度和已完成情况。用户设置日期下限后，旧模板及没有可靠发布日期的模板仍会排除；不会暗中清除约束或拿普通题冒充模板。

服务器只读排查仅提取任务状态、聚合题库/提交计数及筛选配置，没有复制 Cookie、Key、密码、源码或数据库。保留日志窗口内未发现未处理异常；题库覆盖不足及题目名称字段变化得到代码与公开页面证据支持。某账号当日入库为空、同步到的历史 AC 官方日期较早，不据此断言该账号存在遗漏的今日 AC。没有修改线上服务。

## 新增 AI 阅读与报告

1. 元信息只用于初选，提示词明确禁止据此声称已读完整题面。正式入选前，由服务端获取或复用本用户缓存中的完整官方题面，将同题正文、样例、约束与训练上下文交给所选模型阅读确认。
2. 阅读结果必须精确匹配题号并确认适合；非官方导入、空正文、错配、过旧格式、超限或不可用的题面不能假装已读。图片 URL 不等同模型已理解图片。报告不运行用户代码、不交题、不影响完成状态。
3. 报告含题意、约束、适配理由、解题思路、实现要点、复杂度与局限；默认不提供完整可提交程序。报告整批成功后保存到本用户 ai_selection_reports，绑定题面哈希、模型与通道；选题卡仅携带 ai_report_id。
4. 每日随机/专项、指定题目 Roll、独立专项、一般 AI 推荐和工作台中已保存的 AI 推荐均有“查看 AI 报告”。点击先提示原文“此报告为ai生成的代码解析报告，你确定要现在看吗？”，确认才读取正文；取消不请求，读取不调用模型。
5. 查看使用只读 GET /api/selection-reports/{id}，沿用工作区认证与多用户隔离，报告 ID、题目 ID 和报告结果中的题目 ID 都需匹配。加载、重复点击、失败重试、关闭、切题和卸载均按请求代际处理；Markdown 不启用原始 HTML 执行。
6. 题面或报告确认失败时不保存新题单、不消耗 Roll，也不会自动付费重试。旧题单不自动补生成收费报告，而是显示暂无报告的禁用说明。逐题阅读会增加生成耗时与模型费用。
7. 报告生成复用外层任务的并发预算，不重复占槽；生成前后复查候选资格。长期操作需受生成租约与整体时间上限约束，旧请求不得覆盖更新后的计划。
