# 当天做题量排行榜：开发检查

本轮只做本地开发与必要自检，没有连接或部署线上服务。版本保持 0.20.4，不创建标签、发布公告或发布包。

## 修改

- 明确按北京时间当天官方 AC 的不同题目数排名，自主练习、每日任务与对战均计入，不依赖每日题单或签到。
- 保持平台身份认领和公开榜单开关；非本人身份不计入，不公开源码或凭据。
- 兼容旧工作台已核验但未归入提交历史的官方 AC；同一提交已有采集记录时，以采集结果为准，防止旧 AC 覆盖后续重判。
- 新增“同步我的提交记录”入口，沿用既有账号采集、认证、CSRF 与任务限流。完成后通过任务刷新信号更新榜单，避免页面保留旧计数。
- 说明“同步题库”只更新题目资料，个人做题量需同步账号提交或在工作台同步本题；缺少账号或身份认领时给出提示。
- 榜单请求增加响应顺序保护，避免较早请求覆盖后续日期或刷新结果。

## 开发自检

- 后端 `tests/test_social.py`：14 项通过，包括无每日题单时四个平台均计数、每日任务外题目、重复 AC、历史日期和未来记录、其他账号、草稿、失败证据、重判、旧 CF / AtCoder 官方记录以及用户隔离。
- 前端 `src/social.test.tsx`：5 项通过，包括同步按钮、后台任务完成后刷新、缺少账号/未认领提示，以及现有公开范围和对战操作。
- 浏览器 `e2e/social.spec.ts`：3 项通过，覆盖从排行榜发起同步后由主页面任务监测自动更新数量、榜单详情和现有对战操作。
- TypeScript 与生产构建通过，保留现有资源块体积提示；后端保留现有 Starlette/httpx 弃用警告。
- 新增夹具初次复用了同一平台提交号，触发数据库唯一约束；改为不同提交号后重新运行通过，未放宽产品数据约束。

测试使用本地临时数据库、合成判题证据和浏览器拦截响应；没有执行真实平台采集或交题，不代表版本验收。真实平台同步后数量和线上账号认领状态仍待用户指定验收。
