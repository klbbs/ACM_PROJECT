# 多类别抽题、简略题库与公开参考开发记录

## 原路径与修改

- Hermes 原参数只匹配一个专题，外部 QQ 桥接还要求显式输入分数并限制题型长度。服务端保留字符串参数和旧幂等指纹，加入最多8类别的表达式：`&`、中英文逗号为交集，`|` 为并集，交集优先，不接受括号。候选预览、排除诊断和正式选题共用匹配器；细类只接受真实标签或对应专题已批准的方法证据。
- `/roll dp&博弈论` 可省略分数：先取当前聊天上一轮有效分数，否则读取已认证训练目标/区间；无有效配置明确提示。仓库提供无框架依赖的解析器和可选桥接迁移工具，保留原始文件备份；原任务恢复、冻结请求、排重和回执不变。
- 题库批量列表新增小型 `brief_statistics`。CF和牛客仅返回累计通过人数时不生成通过率；洛谷提供同快照提交/通过次数时才计算累计提交通过率。AtCoder复用同次已下载的难度模型。简略信息先用于日期、类别、分数等预筛，再有界补比赛窗口统计；保留既有55%经验/45%官方评分及Gym证据要求，不把累计人数直接换算分数。
- 完整题面读取后，并行查询同题公开题解或公开AC代码，随完整题面交给报告AI；仅使用无凭据的固定官方入口、严格校验题号/提交/判题归属。最多4次GET、12秒、摘录总计8000字符。失败正常降级；急停取消并等待清理。只总结参考思路、不执行或返回完整程序，结果仅附来源元数据；持久结果重发不重新抓取或付费生成。
