# 共享译文匹配与刷新

共享译文只有在管理员审核通过、原题由服务器从官方获取且原题内容匹配时，才进入其他用户的阅读选项。读取共享译文不会调用 AI，也不会创建个人译文副本。

匹配依据包含题号、官方地址、标题、原始正文、样例、图片和时空限制。有原始 HTML 时，派生 Markdown、sections 和渲染版本不参与内容匹配。Codeforces 的小标题曾由 `div` 改为 `h2`；这项排版变更也不视为正文更新。文字、公式、图片地址、样例或限制的真实变更仍会隔离旧译文。

历史贡献保留原来的指纹和记录，读取时使用其存档原题进行兼容匹配，不重写线上档案。同一模型身份因旧排版产生多份等价的已通过译文时，只提供最新的一份；新上传也会检查历史记录，避免重复贡献。

工作台提供「刷新共享译文」；页面可见时每 30 秒及返回页面时同步列表。读取失败保留已有译文并提供重试。翻译任务完成后按任务返回的译文 ID 读取结果；切题后的旧请求不能覆盖新题目。
