# 私人代码模板（0.20.0）

工作台编辑器下方展开「我的代码模板」，填写标题、自定义触发词、适用语言和模板代码，点击「添加并保存模板」。可保存多个模板，再逐个编辑或删除。模板属于当前 ACM Lab 用户，在服务器的该用户私有数据库 `web_settings.editor_code_templates` 中持久化，不向其他用户共享，不会发送给 AI，也不会在管理模板时执行。

在增强编辑器输入触发词，方向键选中候选，按 **Tab** 插入。**Enter 仍然换行**，Esc 关闭候选。中文触发词支持输入法完成后的文字，例如「树状数组」；英文例如 `fenwick`。触发词以字母、中文或下划线开头，后续可含字母、数字、下划线或连字符，最多 40 个字符；不支持空格或其他标点。

模板采用 CodeMirror 片段语法：

```cpp
for (int ${1:i} = 0; ${1:i} < ${2:n}; ++${1:i}) {
    ${0}
}
```

插入后先选中 `i`，同名/同编号占位符联动；Tab / Shift+Tab 跳转到其他占位符，`${0}` 是最后光标位置。也支持 `${name}` 和 `${}`。如果想保留字面量 `${name}`，在模板中写 `$\{name\}`；反斜杠转义花括号后，CodeMirror 不把它当占位符。基础文本框降级模式不提供补全，返回增强编辑器即可使用。

适用语言可以是全部、C++ 通用、C++17、C++20、Python 3、Java 17。同一触发词可以用于互不重叠的语言；例如 C++ 和 Python 各一个 `main`。重叠语言范围内同名触发词被服务器拒绝。当前语言下个人模板优先于同名内置补全，其他内置关键字、语法片段和本地单词继续可用。

每个用户最多 40 个模板，标题最多 80 字符，单份代码最多 8192 字符且不超过 16 KiB UTF-8，全部数据合计最多 128 KiB。模板通过数据库事务和 revision 检测防止多窗口互相覆盖。保存失败会保留表单；冲突时点击「读取最新版本（保留当前表单）」，确认服务器列表和当前表单后再保存。不要在模板中放入密码、Cookie 或 API Key。

模板更新仅重新配置编辑器补全，不重建 EditorView，不会主动覆盖当前代码、光标或撤销历史。已有 64 KiB 编辑器输入限制仍生效；超出限制的模板插入会被拒绝并保留原代码。
