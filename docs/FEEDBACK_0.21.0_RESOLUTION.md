# V0.21.0 反馈处理

本轮读取部署者本地提供的反馈文档，未将包含私人账号、地址的原文复制到仓库。以下按该版本的十条反馈记录行为；更早版本的条目沿用已有功能。

| 条目 | 本轮处理 |
| --- | --- |
| 1. 题库同步与排行榜、他人做题列表 | 题库同步后独立获取今日官方提交，分别显示结果；榜单新增“查看当日题目”，按官方提交时间、平台与题号去重，保留身份验证和公开设置。 |
| 2. 专项无模板、平台覆盖 | 修复洛谷名称字段与模板发现，补充模板分页、专题列表和 AtCoder Library Practice，先匹配专题再截断候选；在本人所有已验证平台内筛选，具体说明日期、难度、模板及已完成排除原因。 |
| 3. 专项生成按钮 | 与每日训练统一主按钮，显示专题与题量，移动端整行，加载与不可用原因可见。 |
| 4. 不等号获取、翻译和渲染 | Vite 按实际 rehype-katex 引擎解析匹配 CSS，修复不同版本布局类不兼容；净化前保留 TeX/MathML，翻译保护不等关系；不改代码中的比较操作，不用字符替换伪装修复。 |
| 5. 隐私与初始管理员 | 首次部署由部署者输入用户名、可选昵称和密码；升级保留已有用户与管理员，不再自动按别名更名、删除或降权。README、历史公告与相关文档去个人化；定向扫描范围见隐私记录。 |
| 6. 唯一默认 AI | 功能页移除重复通道、模型和读取模型控件，自动读取当前用户保存的默认配置；连接与设置是唯一配置入口。API 与可选官方通道的默认选择均保存在用户隔离服务端记录中。 |
| 7. 对战日期限制 | 邀请固化最早发布日期，双方可见，应战不能覆盖；依据 CF 官方比赛开始时间过滤，未知日期及旧无日期邀请不能直接绕过新规则。 |
| 8. 专项难度范围 | 可为本次训练填写 CF rating 范围，参考本人已采集真实评级；非 CF 使用明确来源与低可信宽区间估计，未知不假装满足范围，不声称官方等价。详见难度对照说明。 |
| 9. Tab 与自动缩进 | 修复候选开启时 Enter 清空缩进、行首 Tab 光标位置、行内插入空白及 Vim 普通模式 Tab 误缩进；保留补全优先和用户缩进设置。 |
| 10. 远程提交卡住 | 只读排查确认另一题旧未确认提交阻止新请求。界面显示同账号真正的跨题阻塞任务，提供官方记录、查询和已有人工核对解除入口；明确 409 拒绝不等于本次发送未知，不再将其一律引向 Cookie 更新，不会自动重发未知提交。 |

同时交付逐题官方题面阅读与私人 AI 报告：初选后阅读确认，报告与题号、题面指纹、模型绑定；所有 AI 选题卡及工作台推荐均有“查看 AI 报告”，确认原文“此报告为ai生成的代码解析报告，你确定要现在看吗？”后才读取。旧题单不自动付费补生成。报告不运行代码、交题或改变完成状态。

## 边界

- 没有合格模板时仍不能编题或跳过用户的发布日期、难度条件；旧模板及未知日期模板可能被有效排除。
- 洛谷对照是结合官方等级顺序的人工启发式；AtCoder 对照来自公开第三方统计或分值估计。不同平台难度不存在本轮已证实的精确等价，用户与 AI 均能看到来源和局限。
- 发送结果未知的旧任务不能自动判定未发送；必须先读取官方记录，必要时由用户确认未提交才解除，避免重复交题。
- 只读排查未修改服务器；所有代码回归在本地临时数据、合成平台及模型传输上运行，不冒充真实 OJ 或真实模型效果验收。

最终测试、版本和发布包结果统一记录在对应版本的发布检查文档。
