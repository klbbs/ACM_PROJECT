# 题面翻译稳定性检查（0.18.4）

2026-10-21，用户反馈题面翻译失败频率高，尚未明确所用通道、模型和具体报错。本机开发库与桌面历史库各检查最近100条翻译任务，均无记录，因此没有将本机测试写成服务器失败根因或成功率数据。没有使用个人 API Key、调用付费模型、操作服务器或部署。

## 发现与修改

- 原 AI 路线将整道题的全部文本节点放入一次结构化输出；普通服务已有批次，但单个超长节点仍可超过请求限制。现在 AI 按最多4000字符、48个片段分批，低输出上限会进一步缩小批次。超长 Markdown 节点可拆分、翻译后按原ID重组。超过64批时先提示提高输出上限，不发送大量小请求。
- 公式等保护标记实际为 `ACMPROTECT_<随机前缀>_<序号>_END`，旧提示词举例不匹配。新提示明确实际格式、ID不重编号、片段不合并及句子不完整时的规则。分割不会切开保护标记，Markdown围栏代码整体保护，HTML中的代码和样例保持原有跳过逻辑。
- 每批返回后立即检查 ID、顺序、非空和保护标记；失配停止后续请求。所有批次完成后才暂存，沿用原有最终整份校验。没有自动重试，没有落盘个人译文，也不在失败时共享残缺结果。多批调用可能增加请求数和提示词开销，不能承诺消除上游限流、网络故障或模型格式不遵从。
- 多批结果必须有相同服务器捕获的模型/提供方身份，配置变化时不保存混合来源的译文。
- 翻译控件显示本次任务的失败原因；复用共享结果只关联本次任务，不再由历史已完成任务反复覆盖用户阅读选择。队列拒绝也会在控件中解释，换题清除旧状态。
