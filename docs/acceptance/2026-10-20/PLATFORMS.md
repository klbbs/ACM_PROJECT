| 平台题号 | 官方 HTTP | 解析结果 |
| --- | --- | --- |
| AtCoder abc001_1 | 200 | 日文旧版题面，3 对输入输出样例，var 数学变量转 TeX |
| 牛客 14301 | 200 | 题目【入门班】第 k 大与第 m 大，1 对样例，57 个公式/图片 HTTPS 链接 |
| 牛客 16609 | 200 | 潜伏者，3 对样例 |

| 洛谷 P1001 | 418 | 网络访问受限；普通地址与 _contentOnly 请求都失败，不能声称真实抓取成功 |
| 牛客 1000 / 1001 | 200 | 平台返回无权限页，正确拒绝，未把权限页当题面 |

洛谷解析使用现有账号采集适配器的 lentille-context / currentData / decodeURIComponent 数据解析，合成样例验证 Markdown、公式、图片和样例字段。真实服务器可配置属于该平台的 Cookie 后重试，Cookie 无法保证绕过平台的 IP/访问限制。未绕过验证或执行站点脚本。

四平台题面统一提供给 AI 提示和翻译；账号信息采集与代码提交分开。提交能力当前为官方页导航，不自动代交。保存 Cookie 只表示已配置凭据，不代表已验证登录。Codeforces 提交号关联通过官方即时 API 核验；其他平台先采集官方账号记录，再用本用户数据库中的平台、账号、提交号、题号和时间核验，界面标明其采集时间，未采集时不可关联。远程源码均未核验，不能用本站自测冒充官方判题。四平台已核验非 AC 均可进入 AI 错因复盘。

CF 题库难度不与其他平台难度混算；每日 AI 全题库选题目前仍为 CF；智能选题页可切换其他平台，从当前用户已抓取、尚未做过的官方题面缓存选题。其他平台没有 CF 难度，界面隐藏 CF 难度筛选，候选 difficulty=null。未声称有其他三平台完整题库。
