# 0.15.0 平台只读检查（2026-10-20）

本机开发出口，使用已有本地配置；不展示个人身份、Cookie 或原始响应，不更改凭据，不提交代码。结果不保证与部署服务器一致。

| 平台 | HTTP | 最终判定 | 说明 |
| --- | --- | --- | --- |
| AtCoder | 200 | authenticated | 官方设置页面组合证据，身份与绑定账号匹配 |
| 牛客 | 200 | authenticated | 修复后识别官网当前会话 bootstrap 并核对 UID；修复前 unknown |
| Codeforces | 302 | expired | 官方返回登录入口，当前保存的 Cookie 需要更新 |
| 洛谷 | 418 | blocked / access_restricted | 官方限制本机服务器请求，未提供可确认的验证码标记；不判凭据过期 |

另做不带个人凭据的官方只读探测：CF 与 AtCoder 为302登录跳转；洛谷418；牛客200且官网标记 isLogin=false。牛客解析遵循其当前官方首页及同源 common.js 的 globalInfo.ownerId 会话逻辑，严格静态解析，不执行上游JavaScript。

看到验证码时，网站提供固定官方入口与重试步骤，用户在本人浏览器完成后重新导出Cookie、保存并重检。浏览器验证不会自动解除服务器出口限制；本站不嵌入挑战HTML，也不承诺把服务器验证码会话转移到浏览器。验证码与限流、登录过期、网络错误分别处理。

脚本发布为 .user.js，油猴管理器需支持Cookie API和HttpOnly能力；不支持时明确停止并转F12。普通默认会话外的Firefox容器、隐私窗口、首方隔离拒绝脚本读取，避免误导出另一会话。脚本新增浏览器验收使用合成GM API；本次没有在真实Tampermonkey安装中验证Cookie读取兼容性。
