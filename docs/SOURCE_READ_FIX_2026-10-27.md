# 获取本次代码：开发修复记录

本次保持版本 0.21.4，不创建标签、发布公告或安装包。检查只覆盖源码读取的改动及直接受影响链路。

## 已查明与已修复

此前授权的线上诊断已观察到：CF 判题 API 和本人提交列表可读，列表中的账号、题号和提交号一致；源码列在原始 HTML 中却是 `td.id-cell > span.hiddenSource`。官方内联脚本的 `viewableSubmissionIds` 白名单决定是否将其替换成 `a.view-source[href="#"][submissionId]`。旧实现强制寻找普通提交详情链接，因而误报记录不一致。

- 共用纯解析函数识别普通官方链接、动态源码按钮、白名单明确允许的隐藏占位符。不执行上游 JavaScript，不猜测缺失的授权声明。
- 白名单仅接受明确、唯一的严格 JSON 声明；错误 ID、重复声明、注释或字符串伪造、正则字面量、修改数组、未知用途引用及模板插值均保守拒绝。
- 只有明确的账号、题目或返回提交号冲突才报告不一致；缺少页面证据改为源码入口或内容不可核验。
- 按此前观察到的官方 AJAX 流程补充随机 `rv`、表单内容类型和接受类型，保留官方 CSRF、本人身份和精确提交绑定。这项协议补齐不等于解决真实 403。
- 日志增加账号身份不符、判题记录冲突、判题证据缺失及源码不可核验的固定分类；不记录账号、提交号、凭据、源码或官方响应正文。
