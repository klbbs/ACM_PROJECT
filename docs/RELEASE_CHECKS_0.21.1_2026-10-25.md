## 发布包与隐私

使用项目白名单打包器生成 ZIP、TAR.GZ，校验源码摘要、两种格式的文件集合、版本及构建提交号；最终包在发布提交后重新生成，使 BUILD_INFO.json 对应实际发布提交。发布包留在被 Git 忽略的 releases 目录，不提交二进制产物。检查包含前端构建、专题目录及新增模块，不包含账号配置、Cookie、Key、数据库、浏览器数据、运行日志或原始私人反馈。

仓库定向扫描范围与不能替代完整秘密审计的限制，见 [隐私检查](BOOTSTRAP_PRIVACY_CHECKS_2026-10-25.md) 和 [仓库隐私](REPOSITORY_PRIVACY.md)。没有重写既有 Git 历史。难度估计方法、来源和可信度限制见 [难度对照说明](TRAINING_DIFFICULTY_MAPPING.md)。

## 实际使用仍需确认

- 没有真实交题、调用付费模型或把模拟响应当作官方成功；真实登录、Cloudflare、上游可用性和具体模型报告质量仍需实际使用确认。
- 严格日期、难度及模板条件可能确实没有合格候选；不会清除约束或伪造模板。非 CF 难度只是有来源的宽区间估计。
- 官方提交记录仍按真实提交日期归日，旧 AC 不算今日完成。公开榜单保留身份校验与隐私设置。
- 旧远程发送结果未知时需先核对官方记录，不自动重交；逐题报告会增加生成时间及模型费用，读取已有报告不再次调用模型。
- 本轮仅本地验收与仓库发布，未在服务器执行升级。
