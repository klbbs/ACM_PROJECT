# 连接自动检测与身份自动认领开发自检

日期：2026-10-31。范围仅包含本次连接、登录检测与社交身份认领变更，不代表真实平台登录、交题成功或服务器部署。

## 原因与修复

- 设置页原先保存后串行等待单个账号检测，缺少可追踪后台任务；已有账号重新登录 ACM 时不会自动检测。现在设置页明确发送 `auto_check: true`，站内登录成功也启动当前用户凭据检测；保存与登录不等待平台网络。旧接口客户端省略字段时仍只保存配置，普通 GET 不启动平台请求。
- 身份自动认领原先依赖之后读取社交页面时的惰性处理，扫码与浏览器验证没有即时回调。现在真实验证通过后立即在对应认证用户空间关联身份，Cookie 检测、牛客扫码与洛谷浏览器验证复用同一入口。
- 后台任务按平台账号合并、保留本地间隔和官方限流；检测中更换凭据时只发布最新凭据结果，不用旧 Cookie 的验证证据认领新 Cookie。取消与关闭后清理任务，晚到响应不再关联身份。
- 页面轮询当前凭据的进度和安全结果；轮询失败时恢复手动检测入口。主动解除认领、已有归属冲突与公开偏好均保留；不暴露 Cookie、指纹、原始异常或上游网页。
