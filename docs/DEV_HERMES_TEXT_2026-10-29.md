# Hermes 纯文本输出调整

后续用户要求同时保留文字、图片两种入口，并增加急停等控制接口。当前实现见 [双入口与任务控制开发记录](DEV_HERMES_CONTROL_2026-10-29.md)；下文保留当时纯文本改动与测试结果。

用户要求仅修改本地项目，移除图片输出，改为 AI 阅读题面后直接说明题目。没有连接或修改服务器，没有推送、发版或改版本号。

## 改动

- 复用现有两次 AI 调用：初选一道真实候选、阅读完整官方题面并生成中文题目说明和独立解题报告。移除额外整页翻译、截图渲染与截图前置检查，不再安装 Hermes 专用浏览器/Markdown 依赖。
- 新增严格的 `ProblemExplanation` 输出结构，提供中文标题、已知条件/变量/操作/目标、输入输出和注意事项；约束沿用同一阅读报告，样例直接复制同一官方题面，保留空格和换行，不由模型重写。
- SDK `explain(job)` 可直接供 Hermes 回复用户，不包含解题步骤；`solution(job)` 另取完整解题报告。可选本地保存 result.json、problem.txt、solution.txt，不发生额外下载请求。
- 移除专用渲染实现、KaTeX 副本及截图测试；网站自身的公式渲染和其他功能使用的浏览器依赖不受影响。保留空的 `hermes` extra 兼容旧安装命令。
- 历史任务仍能读取已有报告，明确没有新版中文说明，不自动重新收费生成。旧截图接口核对任务所有者后返回 410，不再提供文件；沿用原约定在进程升级时清理旧的短期截图。
- 保留原有认证、CSRF、限流、幂等、候选与配置/题面指纹核验。开始时工作树已有的候选题号 schema 限定改动及测试保留，没有回退或单独提交。
